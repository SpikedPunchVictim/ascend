# EV-76: reviewer recall for the five unmeasured lens classes, and `time_concurrency` at n = 20

**Status**      Measured 2026-10-22 for `asc-gtnu.15`. **24 of 24 planned reviewer runs completed, 0
                failed, 0 discarded**, $16.0870 of a $20 ceiling. The apparatus was pre-registered and
                sealed 2026-10-20 (`spike/recall/PREREG-gtnu15.md`, sha256 `1220cc86…`) with the seeds
                (`sha256 2b0dbb19…`) before any run; the predictions were fixed in that file and are
                copied verbatim below. **Two predictions hold, two are falsified, one holds for one
                model and is falsified for the other, and the one that lands between its thresholds
                has its mechanism contradicted again.**

**Question**    For `asc-gtnu`, need (4): per lens class, what fraction of known defects does a
                reviewer report through `ReportFindings` — now for the five classes EV-28 never
                measured, and for `time_concurrency` at `MIN_N` = 20 instead of 11.

## Method

Everything is `spike/recall/` as EV-28 left it, with the three changes `PREREG-gtnu15.md` section 1
pre-registered before the runs:

- **Subject.** `packages/core/src/handler.ts` pinned at `25d4504`, sha256
  `9401b4a75c3917d04e176d804582428f87d5e4fc705b342ef2172d3640a5b08c`, matching the seeds'
  `subjectSha256`. **190 seeds**, every class at 20 or 25, each seed measured alone (compiles, breaks
  a committed test) and each class applied together to prove it still compiles — 2026-10-20, all of
  it recorded on the bead before this run.
- **Arms.** A (seeded, runner installed) and C (unseeded control), **arm B dropped**: EV-28 measured
  runner-available against runner-removed at 0.278 versus 0.274, and the runner actually ran in 1 of
  8 arm-A runs.
- **Runs.** 6 classes × 2 models × 2 arms = 24 headless `claude -p` sessions, same brief
  (`brief.md`) as EV-28, `ReportFindings` named in it.
- **Route.** The 2026-10-20 attempt was deferred because the shell routes through a local gateway
  that serves no Anthropic model (`asc-gtnu.15` notes). This run was made with the gateway variables
  unset, so every session used the CLI's own first-party credentials; each session's envelope
  reports `canonicalModel` and `costBasis: list`.
- **Scoring.** `score.mjs` ingests the pruned transcripts into a fresh scratch store and reads the
  `review_finding` entries back. A seed counts as found when a finding names `handler.ts` within R=3
  lines of it. **No finding in this run needed the token fallback: 231 of 231 carried both a file and
  a line**, so every match was made by position.
- **The scorer's seed document is named, not assumed.** `score.mjs --seeds` prints
  `sha256=2b0dbb19… n=190` at the head of the report, which is the document the trees were built
  from (`dogfood/0122`, `asc-3yqq`).

**One apparatus correction was needed at scoring time, and it is reported rather than quietly
fixed.** The trees are pinned at `25d4504`, and the first scoring run used that worktree's own CLI
build, which predates the `api-request-blob` fix (`asc-j6pj`). Every cell reported
`MISMATCH stream=N store=2N`: 231 findings became 462, each duplicated with a `#2` id suffix.
Recall and Jaccard were unaffected (both are set membership), but `findings per run` would have been
exactly double. Re-scored with `ASCEND_BIN` pointing at this checkout's build, **24 of 24 cells
match the stream count exactly**.

## Predictions (verbatim from `PREREG-gtnu15.md` section 3, sealed 2026-10-20)

1. **Recall is under 0.50 in at least 3 of the 6 classes.** At n = 20, a class below 0.50 has an
   upper 95% Wilson bound below 0.66. Falsified if 4 or more of the 6 land at or above 0.50.
2. **`assumption_audit` has the highest recall of the six; `environment_divergence` the lowest.**
   Falsified if `assumption_audit` is not the maximum, or if `environment_divergence` is not the
   minimum.
3. **A seed that fails a committed test is found more often than one that does not, by at least
   0.30 absolute recall, pooled over classes and models.** Falsified if the gap is under 0.15.
4. **The two models' found-sets overlap less than they agree with the truth:** Jaccard under 0.40
   per class, as a pooled figure and per class. Falsified at 0.40 or more.
5. **Seeded reviews report more findings per run than unseeded ones**, per model. Falsified if the
   seeded mean is not higher.
6. **`time_concurrency` scores above the mean of the other five.** Falsified if it is at or below
   that mean.

`time_concurrency` is the one class both runs measured, and `tc01`–`tc11` are byte-identical seeds
with byte-identical trees. Scoring this run's Sonnet session against only those eleven:

```
tc01-11  S=2/11  O=10/11
tc12-20  S=6/9   O=7/9
```

EV-28 measured 8 of 11 for Sonnet on that class and 9 of 11 for Opus. Opus held (9 → 10); **Sonnet
collapsed (8 → 2)**. Its reporting rate moved in the same direction: EV-28's seeded Sonnet mean was
14.75 findings per run, and this run's is 7.67.

The model id is the same string, `claude-sonnet-5`, and every session's envelope reports it as
`canonicalModel`. What changed between 2026-09-27 and 2026-10-22 is the CLI (2.1.307) and the route.
**An 11-seed group is an anecdote under `MIN_N` = 20, and it is recorded as one** — but the direction
is large enough that every Sonnet figure in this record should be read as "Sonnet, on this route, in
this harness, on this day", and the class-ranking predictions P1 and P2 inherit that instability.

## Caveats

- **A class's seeds share one reviewer session.** 20 seeds are not 20 independent observations, and
  the Wilson intervals above are narrower than the truth. The cluster-honest design was priced and
  declined on 2026-10-20; it is still the right design for a cluster-level question.
- **One run per cell, no replicates.** Every model/class/arm cell is a single session.
- **The chance floor is not re-measured here.** EV-28 measured 4.0–20.0% of findings matching a seed
  by position alone on the same file; no figure in this record has been adjusted for it.
- **The scorer's agreement is cited, not re-measured.** EV-28's κ = 0.844 against 40 hand labels
  stands; no new sample was labelled. Every finding here carried a line, so the match was positional
  throughout and the token fallback was never exercised.
- **P3's `n` treats seed-runs as independent and they are not** (same reason as the first caveat).
- **Sonnet's instability** (post-hoc 1) applies to every Sonnet number in this record.
- **The harness's CLI is not the trees' CLI.** The first scoring pass double-counted every finding
  because the pinned worktree's build predates `asc-j6pj`; `ASCEND_BIN` is the fix and the report now
  says so.

## Decision

**Six more classes are measured at n ≥ 20, and the reviewer's recall is a property of the model far
more than of the class.** Opus 60–100%, Sonnet 25–55%, on the same seeds; the class ordering P2
predicted does not survive in either cell, while `time_concurrency` above the mean does.

For `asc-gtnu`: needs (4) is answered for all nine classes. The `asc-gtnu.13` complement is now 57
seeds against 1, and it is still the recall gap rather than a class profile.

For the parent's metric — per-class escape rate — the blocker is unchanged and is no longer about
data: this design has no implementer, so a reviewer's found-set cannot say what *escaped* an
implementer. `asc-gtnu.7` keeps that question.

**Three findings sit outside this record rather than in it:**

- `claude-sonnet-5`'s recall on identical seeds moved 8/11 → 2/11 while `claude-opus-5-5` held:
  a model id is not a model version, and a recall figure is only comparable within one route and
  harness. Filed as `asc-0m1q`.
- The harness pins the subject but not the CLI that scores it, so a run can re-import a bug the
  pinned commit had. The `ASCEND_BIN` comment in `score.mjs` names it; `dogfood/0122` records the
  mirror-image case (a scorer reading a live seed document).
- The run's spend was $16.0870 against a predicted $11.6 — 39% over, still inside the $20 ceiling.
